# Flowkron brand assets

Use the horizontal lockup in header-width layouts, the stacked lockup for centered layouts and the standalone mark for favicons and app icons. Choose the light or dark lockup to suit its background.

The palette uses Blandskron Purple `#4A148C`, Deep Purple `#2E0B59`, White `#FFFFFF` and Near Black `#090909`. The interfaces use green for successful communication states. The editable theme values are in each Angular app's `src/styles.css`. The two `public/flowkron-icon.svg` files mirror `flowkron-icon.svg` here so each app can build independently.

The mark is a speech bubble with connected nodes. The BLANDSKRON wordmark in the signature credits the developer. The primary reference for this draft was the palette and requirements supplied in the rebranding brief.
