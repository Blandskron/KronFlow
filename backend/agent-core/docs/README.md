# flowkron-agent-core docs

Documentacion operativa del servicio FastAPI `flowkron-agent-core`.

Este servicio sigue la misma estructura documental base de `flowkron-operational-service`:

- `ARCHITECTURE.md`: arquitectura y diferencias intencionales.
- `CONFIGURATION.md`: variables de entorno y modos.
- `DATA_MODEL.md`: ownership de datos y tablas transversales.
- `SECURITY.md`: autenticacion, tenant isolation y PII.
- `OPERATIONS.md`: ejecucion, salud y despliegue.
- `TESTING.md`: pruebas locales y validaciones.

Los detalles especificos del agente IA viven en `docs/agent/`.
