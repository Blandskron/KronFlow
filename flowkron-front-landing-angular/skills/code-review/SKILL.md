# Revisión de código

1. Revisa standalone/strict typing, rutas lazy y separación razonable del componente monolítico.
2. Comprueba responsive, temas, semántica, foco, teclado, contraste y labels.
3. Distingue formularios/CTAs demostrativos de integraciones reales.
4. Valida que URLs/número provengan de environment y que no haya secretos en bundle.
5. Ejecuta `npm run build`; usa smoke si cambió comportamiento visual.

No modifiques código cuando el encargo sea únicamente diagnóstico.
