# Git workflow

This repository is a monorepo. Clone the repository root and work in a short-lived branch from `main`. Name branches for the change and refer to the matching issue if there is one.

Open a pull request against `main`. Explain the tested behavior, include migration steps when relevant and run the applicable checks in the [contribution guide](../../CONTRIBUTING.md). Review changes to authentication, tenant isolation, dependencies and deployment with maintainers. Use Semantic Versioning for release tags.
