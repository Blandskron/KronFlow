# Release

1. Lee [`docs/CONFIGURATION_AND_OPERATIONS.md`](../../docs/CONFIGURATION_AND_OPERATIONS.md).
2. Ejecuta build y valida Compose/imagen según alcance.
3. Verifica las cinco configuraciones compiladas; Compose no pasa actualmente las dos URLs de API.
5. Revisa screenshots, accesibilidad, headers, CORS y terceros.

No despliegues/publices de forma autónoma ni expongas tokens o configuración expandida sensible.
