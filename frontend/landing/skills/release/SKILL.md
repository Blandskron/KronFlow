# Release

1. Lee [`docs/OPERATIONS.md`](../../docs/OPERATIONS.md) y su checklist.
2. Ejecuta build, valida Compose e imagen según alcance.
3. Verifica args compilados inspeccionando CTAs/WhatsApp con el smoke.
4. Revisa screenshots, contenido/legal, accesibilidad, headers y terceros.

No despliegues/publices de forma autónoma ni muestres configuración expandida sensible.
