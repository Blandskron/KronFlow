CRM conversacional multi-tenant para WhatsApp e IA

Flowkron es una plataforma modular de código abierto para centralizar conversaciones de WhatsApp, gestionar contactos y pipeline comercial, entrenar agentes de IA con contexto empresarial verificable (RAG) y operar campañas con gobernanza Human-in-the-Loop y cumplimiento de privacidad.

Arquitectura del ecosistema

Microservicios desacoplados con contratos explícitos

Cada dominio opera en su propio servicio con contratos JSON Schema / OpenAPI en flowkron-api-contracts, autenticación JWT RS256 centralizada y aislamiento estricto por tenant.

Auth & IAM

Django
flowkron-auth-service · :8000

Registro con verificación de correo, login + Google Sign-In, JWT RS256 con rotación de refresh tokens, RBAC multi-tenant, onboarding y administración de workspaces.

Operational CRM

FastAPI · PG18
flowkron-operational-service · :8001

Esquema por tenant (`v16`): contactos, leads, pipeline de oportunidades, bandeja HITL, propuestas IA, campañas, consentimiento, privacidad (export/erasure/retention) y KPIs consolidados.

Agent Core (IA + RAG)

FastAPI · Python
flowkron-agent-core · :8002

Ingesta de documentos empresariales (PDF, DOCX, TXT, MD), plantillas descargables, asistente de configuración, simulador RAG con trazas de fuentes y reglas de corrección.

CRM Web App

Angular 21
flowkron-front-app-angular · :8081

SPA privada 100% Zoneless + OnPush con arquitectura Feature-Based/DDD, Design System atómico WCAG 2.2 AA, Vitest, ESLint estricto y Nginx endurecido.

Landing Pública

Angular 21
flowkron-front-landing-angular · :8080

Portal público con identidad glassmorphism claro/oscuro, formulario de contacto protegido por CSRF y modales legales con <dialog> nativo.

WhatsApp & Mail

Node · Python
flowkron-baileys-services · flowkron-mail-service

Conector WhatsApp QR por tenant con webhooks firmados y servicio SMTP-over-HTTP dedicado para correos transaccionales de verificación, recuperación y campañas.

Inicio rápido

Ejecuta Flowkron en local en menos de 2 minutos

Levanta la pila demo completa con datos iniciales o el modo estándar limpio sin superusuario.

Docker Compose (Demo completa con smoke E2E) 
git clone https://github.com/Blandskron/flowkron.git
cd flowkron

# 1. Levantar todos los servicios (Landing :8080, CRM :8081, APIs :8000-:8002)
docker compose -f compose.demo.yaml up --build --wait

# 2. Verificar flujos extremo a extremo
python flowkron-deploy/bootstrap/smoke.py flowkron-demo
